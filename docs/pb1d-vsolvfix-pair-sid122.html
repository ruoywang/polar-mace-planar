7b · Charged: electron density with the ion baseline restored, model vs DFT

Sections 5–7 show the net density n̄ = ion − electron, which is the quantity the model regresses. This is the same charged frame with the ion baseline put back, i.e. the valence electron density itself, on the same z window. Construction, as in the band pipeline: baseline = ne(DFT) + nnet(DFT) (the ion term, a full-grid identity), then ne(ML) = baseline − nnet(ML), hard-clamped at zero and renormalised to the DFT electron count (660.9424 e). Peak DFT density 1.230 e/Å³ at z = 6.93 Å (the carbon sheet); rms difference 2.14e-03 e/Å³, 0.17 % of that peak; largest deviation 8.06e-03 e/Å³ at z = 5.67 Å. The baseline is common to both curves, so the gap is the section-5 net-density error carried onto the absolute scale (rms 1.15e-03 e/Å³ there against 2.14e-03 e/Å³ here; the difference is the clamp and the renormalisation). This is the density from which the section-10 bands were computed. Build: 4571928 grid points clamped at zero, renormalisation factor 0.99971, augmentation-occupancy rmse 4.08e-03, net-density rmse on the grid window 3.04e-02 e/Å³.
