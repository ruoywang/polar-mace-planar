Also fixed on the way (correctness, not speed): the profile-cache freshness test used file mtime, whose granularity on Lustre is 1 s — sub-second MD steps were randomly served stale solvent profiles (trajectories diverged at step 6). The cache file is now always re-read. Measured and rejected: warm-starting the LF/phi solves (net negative after the criterion fix). Run-to-run medians on the same node drift (286/314/245/238 across four production runs); the PB component is pinned at 116–117 ms in every run — the drift lives in the MACE-core side.
