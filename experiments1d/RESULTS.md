## cuEquivariance 探针(2026-07-28)

- 环境 python 3.9.13 + torch 2.2.1/cu121;py3.9 仅能装 cueq 0.1.0
- 0.1.0 源码含 match 语句(需 py>=3.10)→ import 即 SyntaxError,已卸载
- 结论:当前环境不可用;启用需并行建 py3.10+ 推理环境(重装全栈,数小时
  工程 + 全套 parity 门),预期收益 ~75 ms/步(MACE 本体 150→~75)。
  暂缓,除非生产 MD 吞吐需要。
